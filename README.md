# Atma Dashboard — atma.omnisatya.cc

> Mindmap + Gyani + Growth. The soul of Omni, visualized.

## Architecture

```
atma-app/
├── server.py           # FastAPI on :8601
├── mindmap/
│   └── mindmap.py      # Graph generation (copied from ~/omni/)
├── static/
│   ├── index.html      # Dashboard SPA
│   ├── mindmap.html    # Cytoscape mindmap view
│   ├── graph.json      # Pre-generated by omni-mindmap-etl cron
│   ├── css/
│   │   └── dashboard.css
│   └── js/
├── gyani/
│   └── (future: state tracking)
├── systemd/
│   ├── atma-dashboard.service
│   └── tunnel-ingress.yaml
└── README.md
```

## API Endpoints

| Endpoint | Source | Purpose |
|----------|--------|---------|
| `/api/growth` | Supabase `growth_scores_28d` | Per-task + per-domain growth scores |
| `/api/mindmap` | `static/graph.json` | Cytoscape graph data |
| `/api/gyani/lessons` | `~/Obsidian/Curriculum/` | Lessons Gyani has designed |
| `/api/gyani/verifications` | Supabase tasks | Pending + verified verifications |
| `/api/gyani/habits` | WHOOP + Obsidian + git | 7-day habit grid |
| `/api/gyani/alignment` | `~/Obsidian/Curriculum/alignment-reports/` | Latest alignment report |
| `/api/gyani/report-card` | All sources | Aggregated report card |

## Deploy

```bash
systemctl --user daemon-reload
systemctl --user enable --now atma-dashboard.service
```

The Cloudflare tunnel routes `atma.omnisatya.cc` → `localhost:8601`.
Mindmap graph is regenerated by the `omni-mindmap-etl` cron job at 2 AM daily.

## Relationship to Omni

- `omni.omnisatya.cc` (port 8600) — General Omni dashboard (agents, cron, kanban, WHOOP, Edoras)
- `atma.omnisatya.cc` (port 8601) — Atma-specific: mindmap + Gyani curriculum + growth tracking

Both use the same Supabase backend and Obsidian vault. Separate concerns, separate domains.
